\# HAOS Apps



A collection of Home Assistant OS add-ons.



\## Apps



\### LubeLogger



Self-hosted, open-source, web-based vehicle maintenance and fuel mileage tracker.



\- \*\*Author:\*\* \[Hargata Softworks](https://github.com/hargata/lubelog)

\- \*\*License:\*\* MIT

\- \*\*Version:\*\* 1.6.4



\#### Installation



1\. Add this repository to your Home Assistant instance:

&#x20;  - Go to Settings → Add-ons → Add-on Store

&#x20;  - Click the three-dot menu in the top right

&#x20;  - Select "Repositories"

&#x20;  - Add `https://github.com/pewingfield/haos-apps`



2\. Find LubeLogger in the store and click Install.



3\. Start the add-on and click Open Web UI.



\#### Notes



\- Data persists across restarts and rebuilds via HAOS backup system

\- Port 8080 is exposed on your local network in addition to ingress

\- First-time setup is handled automatically on first launch
